# AI Industry Transformation Consultant

An AI-powered digital transformation copilot for strategy consultants — built incrementally, module by module, in Google Colab, as a learning project.

> Portfolio project inspired by Capgemini Invent – Intelligent Industry.

## Status

Environment setup in progress. No modules built yet. See [`docs/progress.md`](docs/progress.md) for a running log of what's built and why, module by module.

## Workflow

Each module is first prototyped and understood in a Colab notebook, then ported into this repo once it works. See `docs/progress.md` for the reasoning behind each design choice as we make it.
